# eSole

## The Idea

<img width="1086" height="530" alt="image" src="https://github.com/user-attachments/assets/eca6c27c-9289-4cb8-bb7a-b8c3577ed47e" />

The sports entertainment industry thrives on creating unforgettable moments, but injuries like Achilles tears, ACL tears, and permanent knee issues are definitely not the kind of drama anyone wants to see. 

Like many medical conditions, leg and foot injuries benefit greatly from early detection. However, many athletes and everyday people fail to realize when their biomechanics are going wrong until an injury actually happens. If only there was an unnoticeable shoe sole that could alert athletes and individuals to mechanical issues before they turn into serious problems!

---

## Now There Is!

<img width="1019" height="631" alt="image" src="https://github.com/user-attachments/assets/56fcf4b7-50b7-466d-8c2a-c53b954fa26f" />

**eSole** combines a flexible PCB with a rigid PCB to measure capacitance between two halves of the flexible PCB wrapped around foam. This setup detects when and where pressure is being applied across the foot.

### Key Features
* **ESP32 Microcontroller:** Handles data processing and sends analytics via Bluetooth.
* **Integrated Design:** Both halves of the flexible PCB are integrated into a single unit to reduce manufacturing costs.
* **MPR121 Controller:** Dedicated to sending capacitance values via I²C.
* **Removable Case:** Designed for easy access and removal.
* **Power Management:** Optimized to run safely on a LiPo battery while supporting charging and programming through USB-C.
